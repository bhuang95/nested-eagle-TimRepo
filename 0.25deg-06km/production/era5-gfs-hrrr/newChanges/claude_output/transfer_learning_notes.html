Stage1b Transfer Learning Setup

The stage1a checkpoint exists at .../stage1a/checkpoint/29a70980e917421697a9dd9d9e3c07ff/last.ckpt (the 702 MB full checkpoint). Here is how the transfer-learning knobs work and what still needs to be set.

The one thing you must change

In stage1b_bo.yaml, fork_run_id is still the OmegaConf mandatory-missing sentinel:

fork_run_id: ???

Set it to the stage1a run_id:

fork_run_id: 29a70980e917421697a9dd9d9e3c07ff

This matters because your warm_start path is built from it (line 240):

.../stage1a/checkpoint/${training.fork_run_id}/last.ckpt

So once fork_run_id is set, warm_start resolves to the checkpoint above, which exists.

The other variables — already correct, here is why

VariableValueRole
transfer_learning true ✓ Loads weights via the transfer-learning loader, which tolerates architecture/shape mismatches and partial loading. You need this because stage1a is o48 / 1.00° and stage1b is o96 / 0.25° — different graphs, so the encoder/decoder/edge tensors differ.
load_weights_only true ✓ Loads only model weights, not optimizer state, epoch counter, or LR-scheduler state. Required for a fork — you want a fresh optimizer with stage1b's own LR schedule (warmup 1000, rate 3.125e-05, max_steps 60000).
run_id null ✓ run_id is for resuming a run in place (continues optimizer/epoch). Keep it null so a brand-new run + output dir is created instead of resuming.
fork_run_id set this Identifies the source run to initialize weights from.

The mental model: run_id = resume the same run; fork_run_id = start a new run seeded from another run's weights. For transfer learning you want fork, so run_id: null + fork_run_id: <source> + transfer_learning: true + load_weights_only: true.

One heads-up unrelated to transfer learning

Line 224, the mlflow save_dir, points at stage1a's mlflow dir:

mlflow: ${oc.decode:${oc.env:SCRATCH}}/.../era5-gfs-hrrr/stage1a/logs/mlflow/

stage1a uses plain mlflow (relative). If you want stage1b's tracking logs kept separate, change this to .../stage1b/logs/mlflow/. Not required for training to run — just where logs land.
